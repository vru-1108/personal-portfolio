# Vrushali Mhaskar — AI Engineer Portfolio

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript. It is ready for GitHub Pages.

## 1. Personalize before publishing

Open `index.html` and replace:
- `vru-1108` with your GitHub username.
- `YOUR-LINKEDIN` with your LinkedIn profile slug.
- `YOUR-EMAIL@example.com` with your professional email.
- The sample GitHub project links with the actual repositories.

Review the experience and project descriptions before publishing. Add a downloadable resume link if you want one.

## 2. Publish with GitHub Pages

1. Create a new public GitHub repository named `vru-1108.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the deployment to finish. Your site will be available at `https://vru-1108.github.io/`.

If you use a repository with another name, the site URL will be `https://vru-1108.github.io/REPOSITORY-NAME/`.

## 3. Update later

Edit the files directly on GitHub or upload updated files. GitHub Pages republishes the site after each commit.

No build tools, paid hosting, or API keys are required.
